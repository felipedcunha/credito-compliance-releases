# Crédito & Compliance — Instaladores e Atualizações

Este repositório hospeda **apenas os instaladores** e os metadados de atualização
automática do aplicativo **Crédito & Compliance (Redwood)**.

- O **código-fonte é privado** e não está aqui.
- Os instaladores ficam em **Releases**: baixe a versão mais recente para macOS (.dmg)
  ou Windows (.exe). O app instalado se mantém atualizado automaticamente.

Uso interno — Redwood Asset Management.
